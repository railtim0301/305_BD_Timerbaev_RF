# Task01 — Подготовка окружения и данных

## Структура файлов данных

| Файл | Разделитель | Описание |
|------|-------------|----------|
| ratings.csv | `,` | Оценки пользователей. Колонки: `userId, movieId, rating, timestamp` |
| movies.csv | `,` | Фильмы. Колонки: `movieId, title, genres` (жанры через `\|`) |
| tags.csv | `,` | Теги пользователей. Колонки: `userId, movieId, tag, timestamp` |
| users.txt | `\|` | Пользователи. Колонки: `id, name, email, gender, birthDate, occupation` |
| genres.txt | — | Список жанров (по одному на строку) |
| occupation.txt | — | Список профессий (по одной на строку) |

## Результаты выполнения

- `ratings_count.txt` — минимальный и максимальный ID пользователя из `ratings.csv` и количество строк с этими ID.
- `sqlite.txt` — версия установленной СУБД SQLite, необходимые для работы файлы и доступные режимы вывода `.mode`.

## Версия SQLite

3.53.4 (2026-07-24, 64-bit)
